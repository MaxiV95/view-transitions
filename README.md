## 🚀 Project Structure

> ⚙️ This is a basic Astro project with Tailwind CSS, configured for simple deployment to GitHub Pages.

> 👀 Feel free to take a quick look at the configuration.

**📁 Inside of this Astro project, you'll see the following folders and files:**

```text
/
├── public/
│   └── favicon.svg
├── src
│   ├── assets
│   │   └── astro.svg
│   ├── data
│   │   ├── colors.ts
│   │   └── pages.ts
│   ├── layouts
│   │   └── Layout.astro
│   └── pages
│       ├── [n].astro
│       ├── [slug].astro
│       └── index.astro
├── astro.config.mjs
├── package.json
└── tsconfig.json
```

To learn more about the folder structure of an Astro project, refer to [guide on project structure](https://docs.astro.build/en/basics/project-structure/).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./docs/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
